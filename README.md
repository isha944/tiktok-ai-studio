# TikTok AI Studio

AI Video Creator is a simple and powerful tool for creating engaging AI-generated videos for TikTok, YouTube Shorts, Facebook Reels, and Instagram Reels.

## Features
- AI video creation
- Vertical 9:16 video format
- Text-to-video prompts
- Voice-over and narration support
- Social media content creation
